## Дальше
- Пациент попадает в очередь и на ТВ только после «Отметить приход» (номер выдаётся при приходе). У врачей заполнить «Кабинет» и «Буква очереди». Создать ТВ-экран («Очередь» → «Экраны»), открыть `/tv/<код>` на телевизоре и нажать OK на пульте. Вызвать тестового пациента: должны прозвучать сигнал и голос.
- Прослушать русский голос в холле. Если звучит нечётко — другой голос OpenAI (`OPENAI_TTS_VOICE`) и перегенерация `--only=ru --force` (`docs/queue.md`, «Голос»).
- Проверить печать талона на реальном чековом принтере 58/80 мм.
- Мелкие доработки по итогам ревью (не блокируют): дата у «Выдать номер»/«Талон», таймаут запроса на странице «Очередь», баннер вместо затемнения после ночной перезагрузки ТВ, неактивные врачи в настройках экрана, проверка REPORTS_TIMEZONE при старте.

## Заметки
- Локально проверять только на стенде (`VITE_API_URL=http://127.0.0.1:4401`): `apps/web/.env` указывает на production.
- Ключи OpenAI и Azure не печатать и не коммитить. Клипы OpenAI генерируются с `--env-file=../../services/api/.env`; ключ Azure — только в переменных текущего окна терминала.
- ТВ: Chromium ≥ 87; надёжнее мини-ПК с Chrome в режиме киоска (`--kiosk --autoplay-policy=no-user-gesture-required`).
- Коммит в `main` выкладывает web (Vercel); API (Render, корень `services/api`) перевыкладывается только при изменениях в `services/api`.
