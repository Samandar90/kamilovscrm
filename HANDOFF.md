## Заметки
- Стенд `queue-preview.cjs` теперь включает лиды: аккаунты `operator`, `marketer`, `marketer2` (пароль `preview`), источник «Реклама Instagram» читает встроенный образец таблицы без сети; любая другая ссылка на стенде читается из Google по-настоящему.
- Зависший запрос 03.10.2026 в 10:33: поиск пациента висел в браузере больше 5 минут и до API не дошёл. Браузер ходит к API по HTTP/3 (QUIC). Два замера по 4 минуты с этого ПК (HTTP/2 и HTTP/3) прошли без единого сбоя, то есть сбой эпизодический. Если зависания повторятся, проверить с выключенным QUIC в Chrome (`chrome://flags/#enable-quic`).
- Как искали причину медленной работы: логи и метрики Render (сервер и база простаивают, CPU около 1%), замеры с этого ПК: до сервера около 100 мс на запрос, потери пакетов 1–2%, Cloudflare отвечает из Варшавы.
- Локально проверять только на стенде (`VITE_API_URL=http://127.0.0.1:4401`): `apps/web/.env` указывает на production. Счета на стенде очереди не реализованы. Если порт 4401 занят стендом другого чата, запустить временную копию `queue-preview.cjs` с другим портом и направить на неё `VITE_API_URL`; копию не коммитить.
- Как замерять размер ответа в production: логи Render сервиса API, тип `app`, текст `GET /api/appointments*`. В строке лога стоят размер ответа до сжатия и время ответа. Ни одна страница больше не запрашивает `GET /api/appointments` без параметров: такая строка в логе после 03.10.2026 означает вкладку, которую не обновили после выкладки.
- Ответы API сжимаются по пути к браузеру: Cloudflare перед Render отдаёт JSON с `content-encoding: br` (проверено 03.10.2026 на `/health`). Размеры ответов в логах Render и цифры в этом файле даны до сжатия.
- Тесты API больше не требуют `services/api/.env`: `npm test` проходит и в свежем worktree. В свежем worktree нет `node_modules`: сначала `npm ci` в `apps/web` и в `services/api`.
- Ключи OpenAI и Azure не печатать и не коммитить. Клипы OpenAI генерируются с `--env-file=../../services/api/.env`; ключ Azure — только в переменных текущего окна терминала.
- ТВ: Chromium ≥ 87; надёжнее мини-ПК с Chrome в режиме киоска (`--kiosk --autoplay-policy=no-user-gesture-required`).
- Коммит в `main` выкладывает web (Vercel); API (Render, корень `services/api`) перевыкладывается только при изменениях в `services/api`.
- В логе API нет текста сообщений ИИ и значений из базы. Для локальной отладки: `DEBUG_AI_TEXT=1` (текст сообщений, промптов и ответов) и `DEBUG_ERROR_DETAILS=1` (ошибка целиком, с `detail`; действует и на `npm run db:migrate`); в production оба флага не включаются (`config/env.ts`, для миграций — в самом `db-migrate.cjs`). Суммы выручки ИИ-ассистента (`[AI FACTS] revenueToday…`) в логе остались: это не личные данные.
